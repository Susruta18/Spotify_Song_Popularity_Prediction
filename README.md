# 🎵 Spotify Song Popularity Prediction

## 📌 Overview
This project uses Machine Learning techniques to analyze Spotify music data and predict song popularity based on different audio features.

## 🛠️ Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

## 📊 Project Workflow
- Data Collection
- Data Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection
- Model Training
- Model Evaluation
- Popularity Prediction

## 📁 Project Structure
```text
Spotify_Song_Popularity_Prediction/
│
├── Spotify_Song_Popularity_Prediction.ipynb
├── Spotify_Dataset.csv
└── README.md
```

## 🚀 How to Run
1. Clone this repository.
2. Open the notebook using Google Colab.
3. Upload the required dataset.
4. Run all cells sequentially.
